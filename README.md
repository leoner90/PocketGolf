# Pocket Golf

Pocket Golf is a portrait mobile arcade game made in Unity.

The player aims the ball with a mouse or finger, avoids dangerous holes and water, collects coins from blue holes, 
and tries to survive before the timer reaches 0.

## Rules

- Red hole: -10 seconds
- Water: -10 seconds
- Blue hole: +5 seconds and +1 coin
- Mud slows the player down
- Walls are obstacles and can bounce the ball
- Timer <= 0 means Game Over


## Controls

Drag behind the ball to aim.

The aim line shows the hit power.  
Release to shoot the ball in that direction.

## Features

- Portrait mobile gameplay
- Touch and mouse controls
- Random hole changes
- Warning flash system
- VFX and sound effects
- Camera auto-scaling maybe it even works! :)
